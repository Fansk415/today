# 今日

给自己用的日程与期限提醒。纯本地，没有服务器、没有账号、不上传任何数据。

## 它管什么

- **今天要做的**：一打开就是今天的事，勾掉就走。
- **期限倒数**：比赛材料、实验报告、期中考试，剩 3 天变黄、剩 2 天变橙、过期变红。
- **今天的课**：几点、在哪、哪一节正在上。
- **起床时间**：记在顶部，真正的闹钟还是用 iPhone 自带「时钟」。

## 在 iPhone 上用

这个工具是一个网页，装到主屏幕后和 App 一样：全屏、有图标、断网也能开。

1. 用 **Safari** 打开部署好的网址（不能用微信内置浏览器）。
2. 点底部 **分享** 按钮 → 往下滑 → **添加到主屏幕**。
3. 桌面上出现橙色的圆环图标，以后从那里打开。

> 数据存在这台手机的 Safari 里。清除 Safari 网站数据会丢失，换手机前先在「设置 → 数据」里导出备份。

## 日常用法

| 想做什么 | 怎么做 |
|---|---|
| 加今天要做的事 | 首页「今天要做」下面的输入框，写完按回车 |
| 加一个期限 | 「全部」→ 右上「+ 加期限」 |
| 加一节课 | 「全部」或「设置」→「+ 加课」 |
| 让 iPhone 提前提醒期限 | 「设置」→「导出到苹果日历」→ 在「文件」里点开 .ics 导入 |
| 备份 | 「设置」→「导出备份」 |

## 本地预览（电脑上）

双击 `启动.cmd`，浏览器会打开 `http://localhost:8767`。

或者：

```bash
python -m http.server 8767 --directory .
```

## 已知边界

- 只有一台设备。不做多设备同步，迁移靠导出 / 导入 JSON。
- 没有真正的推送通知（网页做不到）。需要「响」的部分交给系统：期限经「导出到苹果日历」进日历后，会在截止前 3 天、前 1 天和当天早上 9 点各提醒一次；每天早上的固定提醒用系统「提醒事项」建一条重复项。「设置 → 让手机主动提醒你」里有这三步的完整说明。
- 数据在浏览器本地存储里，清缓存前记得导出。
